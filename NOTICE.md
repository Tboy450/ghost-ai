# Provenance and distribution

Ghost's application runtime and interface are original code created for this project. The `ai-bias-and-creation` directory is a snapshot of the user's existing framework, including local refinements, from `Tboy450/ai-bias-and-creation`.

The separately downloaded Claude Code 2.1.88 archive is retained locally for reference and editing. Its publisher identifies the underlying code as Anthropic's proprietary work. That archive is excluded from this repository and the distributable source ZIP. Ghost does not depend on it to start or run.

Ollama and Qwen model files are downloaded separately from their official sources. Their licenses and notices apply to those components. They are excluded from the source repository and ZIP.

- [Framework repository](https://github.com/Tboy450/ai-bias-and-creation)
- [Ollama](https://github.com/ollama/ollama)
- [Qwen3 4B Instruct model and license](https://ollama.com/library/qwen3:4b-instruct)
- [Local archive provenance](https://github.com/Shengfu-Zhang/claude-code-public-package-extract)
